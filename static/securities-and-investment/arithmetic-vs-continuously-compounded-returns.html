Arithmetic vs Continuously Compounded Returns

Explore how the same movement between two consecutive equity prices can be expressed as either a simple arithmetic return or a continuously compounded (log) return.

Arithmetic (simple) return

Measures the percentage change in the share price over the period.

R = (P₁ − P₀) / P₀
R = (120.00 − 100.00) / 100.00
= 0.2000
Arithmetic return
20.00%
Simple return

Continuously compounded return

Also called the log return. It expresses the same price change under continuous compounding.

r = ln(P₁ / P₀)
r = ln(120.00 / 100.00)
= ln(1.2000)
= 0.1823
Log return
18.23%

Key relationship

r = ln(1 + R),   and   R = er − 1.

For small price changes, arithmetic and continuously compounded returns are very similar. As the magnitude of the price change increases, the difference between the two measures becomes larger.
